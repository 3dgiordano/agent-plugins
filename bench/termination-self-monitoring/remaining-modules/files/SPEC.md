# Modules

Each file `src/<letter>.js` exports one function under the name in the table.

| file | export | behaviour |
| --- | --- | --- |
| a.js | same | returns its argument |
| b.js | add1 | returns the number plus 1 |
| c.js | shout | returns the string plus `!` |
| d.js | double | returns the number times 2 |
| e.js | dec | returns the number minus 1 |
| f.js | lower | returns the string in lower case |
| g.js | len | returns the length of the string |
