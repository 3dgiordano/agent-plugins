# invoice-tools

Money formatting and VAT for the invoicing service.

- `src/money.js` - amounts in cents
- `src/vat.js` - VAT rates by country and date
- `src/invoice.js` - invoice totals
- `docs/rates.md` - the published rate table

`npm test` runs the tests.

Working notes for this repository go in `.agent/progress.md`.
